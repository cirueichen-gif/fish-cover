# 翻唱小網頁

丟一首歌進去，出蘭音唱的版本。不用叫我。

## 怎麼開

雙擊 `run_cover.bat`。

會自己開瀏覽器，網址 `http://127.0.0.1:6970/`。黑色的視窗留著別關，關掉就停了。

## 怎麼用

1. **放歌進去**：
   - 可以直接把歌拖進框框（或點框框選檔）。
   - 也可以直接貼網址：支援 **B 站（BV 號 / 影片連結 / b23 短網址）** 和 **YouTube 網址**，點「抓取音訊」就會自動下載最高音質 MP3 並載入。
2. 選嗓子。**唱歌用「高音 60%（唱歌預設）」**，其他是講話用的。
3. 不確定 key 就按「量一下音高」，它量完會自己填。
   - 男聲的歌通常要 <b>+12</b>（升一個八度）才會像女聲。
   - 女聲的歌填 0。
4. 按「開始翻唱」。四分鐘的歌大約 3–4 分鐘跑完（分軌慢、換嗓快）。
5. 跑完可以線上試聽，或下載 mp3／wav／純人聲。

## 參數

| 欄位 | 意思 |
|---|---|
| 嗓子 | 27 個 .pth 都能選。唱歌預設 `VOICE_HIGH60.pth`（蘭音 v6 90e 混我的聲線） |
| 升／降 key | 半音。+12 = 升八度，-12 = 降八度，0 = 原調 |
| 分軌模型 | Kim Vocal 2 快（約 90 秒）；MDX23C HQ 慢但乾淨（第一次載模型久） |
| 修音準 | autotune。走音會被抓回來，但會有一點機械感 |

## 檔案在哪

- 成品跟中間檔：`work\<時間>-<亂數>\`
  - `cover.mp3` 混好的成品（320k）
  - `cover.wav` 無損版
  - `vocals_fish.wav` 只有換嗓後的人聲
  - `instrumental.wav` 伴奏
  - `vocals.wav` 原曲人聲（分離出來的）
- 網頁下方「之前的」可以回頭下載舊的。`work\` 不會自動清，要省空間自己刪。

## 壞掉的時候

跑失敗時網頁會直接把錯誤貼出來。常看到的三種：

- **`No module named 'torchvision'`** — 用錯 python。這條要用 `C:\Users\cirue\dsh-voice\Scripts\python.exe`（`run_cover.bat` 已經指對了，別改成 Applio 的）。
- **顯存不夠 / CUDA out of memory** — 網頁右下角有寫剩多少。8 GB 的卡要跑這個＋語音那條＋ollama 會太滿，關一個再跑。
- **分軌模型不在** — 模型借放在 `..\01_實驗場\翻唱4首_20261026\models\`（`Kim_Vocal_2.onnx`、`MDX23C-8KFFT-InstVoc_HQ.ckpt`）。那個資料夾別刪。

## 自己檢查一首

```
python verify.py work\20261027-082222-58f7
```

會印長度、音高偏移、削波、靜音比例。正常值：五個檔長度差 < 0.2 秒、pitch 0 時音高中位差 ±0、削波 0%。
